# Yoonhee Choi – Academic Website

This repository contains the source files for my personal academic website.

The website includes information about my research, teaching experience, and curriculum vitae.

## Website

https://yoonheechoi0613.github.io

## Built With

This website was created using Quarto and RStudio and is hosted with GitHub Pages.

## Repository Structure

- `index.qmd` – Home page
- `research.qmd` – Research and publications
- `teaching.qmd` – Teaching experience
- `cv.qmd` – Curriculum vitae
- `_quarto.yml` – Website configuration
- `styles.css` – Custom website styling
- `docs/` – Rendered website files used by GitHub Pages

## Reproducing the Website

To reproduce the website:

1. Clone this repository.
2. Open the project in RStudio.
3. Install Quarto if necessary.
4. Open the Quarto project.
5. Render the website using the **Render** button in RStudio or run:

   ```bash
   quarto render
